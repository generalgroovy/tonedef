# Guitar playback

Settings > Sound > Guitar selects a synthesized plucked-string tone. New projects default to Guitar; saved projects retain their explicit Sine/Triangle selection, so select Guitar once for an existing save. No sample downloads or dependencies are required.

Chord picking: Free defaults to a down-strum; Down traverses ascending physical string IDs; Up reverses that order; Alternate switches direction by event index. Re-entrant tuning never changes string order. Fingers retains simultaneous plucking. Successive sounded strings start 25 ms apart, capped at eventDuration/(noteCount+1) for short events. Silent strings are skipped. Notes overlap; the event duration and tempo stay unchanged. Hear uses the same planner for the selected event, without looping or metronome. Single-note editing audition remains brief.

Rebuild: src/audio.js creates a normalized PeriodicWave with zero real coefficients and harmonic h=1..16 imaginary coefficient sin(pi*h*0.19)/(h*h*0.19). Route oscillator -> lowpass (Q 0.35) -> gain -> destination. Frequency remains exact 12-TET. Filter cutoff starts at min(0.45*sampleRate,16*fundamental), exponentially decreases to min(0.45*sampleRate,max(180,2.2*fundamental)) over min(0.3,0.8*duration) seconds. Gain attacks in 3 ms or duration/4, whichever is shorter; decays exponentially to 16% at 85% of duration and 0.0001 at the end. Disconnect oscillator/filter/gain when ended; Stop cancels gain automation and all scheduled sources. This is a guitar-like synthesized tone, not an acoustic-guitar recording.

Playback display: Player's audio-clock callback updates transient playingId; boardEvent resolves that event, falling back to the editing selection when stopped. Rebuild only the fretboard, its label and chord lines; preserve board scroll and reconnect ResizeObserver. Chord-root colors use the sounding event. Lock fret editing while playback is active without dimming notes. Timeline editing selection, project storage, undo and inspector remain unchanged. Stop/completion restores the editing fretboard. Rests show no selected notes or chord lines.

Validation: 31 local automated groups passed, including re-entrant string order, upstroke reversal, short-event timing, finger plucks, harmonic/filter/envelope routing, node cleanup, loop scheduling and pending-resume cancellation. Local browser showed C then Cm with their matching frets and lines, restored C on Stop and reported no console errors. Existing browser regression now checks sounding card/name agreement and restoration. Human listening evaluation is not claimed. Publication status must be checked separately from local tests.
