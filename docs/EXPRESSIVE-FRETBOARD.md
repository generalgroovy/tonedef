# Expressive fretboard — 1.3

## User contract

Hear clicks is on by default in new projects (SCHEMA.audition=true); explicit saved on/off values survive imports and reload. Its fretboard checkbox and Settings checkbox control the same setting and existing randomization flag. Volume zero remains silent. Edit mode: a tap hears then toggles a position; a drag previews sound only and never rewrites the chord/melody. Explore: taps/holds never edit. Key mode/right-click/Shift+F10 still edit key membership without previewing a note. Pattern playback temporarily locks fret interaction.

Hold a fret and move horizontally for a continuous slide along that physical string, or vertically for a bend that raises the original pitch by up to two semitones. Return toward the starting point to release the bend. First movement beyond 8px locks the gesture; vertical wins if abs(dy)>1.3*abs(dx), otherwise horizontal. Bend amount=min(2,abs(dy)/40) semitones. Slide linearly interpolates MIDI pitch between actual rendered fret centers, using the starting center plus pointer dx (not the initial off-center click position). Sort centers by screen x, so left-handed layouts, capo/open positions and visible fret gaps work. Clamp to rendered endpoints; do not change strings. A glowing disc follows the nearest slide pitch; the starting disc glows for bends. Readout shows nearest named pitch, gesture and cents from the starting note (100 cents=one semitone).

In Explore, hold Space or Enter on a focused fret. Left/right arrows change pitch by one semitone in physical screen direction; up/down raise/release a bend in 0.25-semitone steps bounded from the original pitch to +2. Release Space/Enter to stop. Arrow keys alone retain fret navigation. Escape, Stop, blur, hidden tab, pointer cancel/lost capture and UI rerender cancel active expression. A 20-second cap prevents stuck holds. One pointer/voice is active at a time. Ignoring secondary pointers prevents accidental multitouch edits; mouse, pen and primary touch share the path.

## Rebuild modules and lifecycle

Add src/expression.js (imported by app.js) with pure bendAmount and slidePitch helpers plus installExpression. It owns a separate Player for note preview and delegated document pointer/click/keyboard listeners, so normal editing commits stop timeline playback without truncating a released preview. On primary left pointerdown of an enabled fret, if audition on, tool not key and transport stopped, snapshot same-string fret geometry, focus/sound the starting note and capture the pointer. On move after threshold, update the smoothed oscillator frequency and existing readout/highlight without rendering the app. On up, release the voice and pointer capture. Suppress the subsequent captured click after a drag/cancel; allow ordinary tap click to reach editing. Pointer taps already sounded on down, so app's click handler only auditions detail=0 keyboard/programmatic activations. Explore click returns without editing. Prevent keyboard default activation for held Space/Enter.

Cancellation invalidates pending AudioContext resume. If release occurs before voice creation, cancel rather than playing a late sound. Each async hold result is checked against the still-active gesture; release stale results. Active expression is cancelled before rebuilding DOM. Suppressed clicks expire after 700ms and reset at the next primary note pointerdown. Pointer move ignores other pointer IDs. Release after cancellation is harmless.

Extend Player.voice with optional held=false argument, returning pitch and release methods. Keep ordinary playback envelope unchanged. Held guitar uses the existing harmonic/lowpass excitation but reaches 16% gain at 0.8 seconds, then decays toward silence by 20 seconds. pitch accepts finite fractional MIDI, clamps 0..129, computes 440*2^((midi-69)/12) and calls oscillator.frequency.setTargetAtTime with 8ms time constant. release is idempotent: cancelAndHoldAtTime(max(currentTime,start+0.16)); exponentially ramp to 0.0001 over 0.14 seconds; stop at releaseTime+0.16. This leaves a short audible pluck for taps. Node membership and released flags prevent updates after Stop/end. Player.hold cancels previous voices, resumes AudioContext under a user gesture with revision guard, and starts a held voice at currentTime+5ms using volume/100*0.22 and selected waveform. Existing Stop and onended disconnect all audio nodes.
