# Visual workspace — 2026-09-18

Full-width fretboard, single-ribbon pattern editor and an adjacent theory workspace replace the numbered headings, introductions and persistent explanatory paragraphs. The inspector and rank motion sit alongside the fifths/chromatic wheel and a permanently visible numerical interval matrix. Examples live under Settings. Important warnings, action names, pitch names, units, locks and reference labels remain visible.

## Half-step semantics

One half step is one semitone. The matrix shows **signed absolute pitch distance** from row to column, including octaves: C3 → E4 is +16, not 4; reversing that pair gives −16. Selecting a cell updates frequency ratio `2^(n/12)`, both frequencies with A4 = 440 Hz, cents `100*n`, and a separately labelled `n mod 12`. These are equal-temperament ratios, not just-intonation ratios. The pitch axis uses linear half-step distances; unisons share a point with an occurrence count.

Fretboard and inspector distances follow the visible interval reference. Tonic and chord-root references are pitch classes, so their displayed offsets are modulo 12. A pinned MIDI note produces signed distances including register. The ½ steps switch changes only the view, not notes or saved settings. Spelled intervals remain visible beside the matrix's primary numbers. Scale steps are the ascending cyclic gaps in the current collection and sum to 12, including custom collections whose tonic is absent. The fifths wheel adds 7 modulo 12; the chromatic wheel adds 1. Rank motion retains the original sorted-pitch comparison and does not infer independent voices.

## Help and colors

Explanations use a single delegated tooltip (`src/help.js`), available on hover and keyboard focus; question-mark controls also open it by tap. Escape dismisses it without moving focus. Pointer movement onto the tooltip keeps it visible. Ordinary note actions are never consumed by a help-only first tap. Native labels, accessible names, and text descriptions remain present. This follows the interaction considerations in W3C's Content on Hover or Focus guidance; it is not a claim of a full accessibility audit.

Backgrounds, borders and text are slightly brighter. Displayed note colors mix 12% white into the existing interval colors; original palette settings and exported JSON are not rewritten. Focus, reduced-motion and forced-color rules remain available. Fret targets are at least 44px high for mouse use and 50px on coarse pointers.

## Implementation and validation

`compact.css` is the visual layer over the original styles. `src/app.js` renders the compact view directly; there are no mutation observers, timers that rewrite layout, application dependencies, or data migrations. The pure `src/interval-view.js` handles numeric geometry and matrix markup. Audio, generator, theory and project-model modules are unchanged.

Run `npm test`, `npm run check`, `npm run build`. The six new unit tests cover all 16,384 MIDI-pitch pairs, octave/direction semantics, invalid data, unison grouping, compound labels and non-mutating view selection. Browser validation is `node scripts/check-layout.mjs` after installing Playwright 1.57.0 and Chromium outside the application dependencies. A full Git history is required for comparison with release `a56e153`.

The browser runner serves actual built ES modules over HTTP, checks 13 desktop/touch-emulated widths from 320 to 2560, exports before/after screenshots and measured geometry, exercises note editing, keyboard controls, matrix selection, help, playback, settings, generation, twelve strings, 36 frets, re-entrant tuning and rests. The baseline is the actual previous release, not the new DOM with styles disabled. Browser results are generated by the workflow and retained in its `compact-ui-evidence` artifact; real-device, Safari, Firefox and screen-reader testing are not covered by that workflow.
